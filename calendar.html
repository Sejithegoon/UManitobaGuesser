3. Add the file to your calendar

iPhone or iPad

Open the downloaded file (Safari shows it in Downloads, or in the Files app) and tap Add All. Choose which calendar to put the classes in.

Google Calendar

On a computer, go to calendar.google.com, click the gear, then Settings → Import & export → Import. Pick the file and the calendar. The Google Calendar app on phones will show them too.

Apple Calendar (Mac)

Double-click the file and choose a calendar. Or use File → Import.

Outlook

In Outlook on the web, go to Calendar → Add calendar → Upload from file. In the desktop app use File → Open & Export → Import/Export.

Good to know

  • This is an unofficial tool built from UM's public class schedule. Always confirm your timetable in Aurora.
  • Room locations aren't in the public schedule, so events don't have one.
  • Classes with no set meeting time (like online or flexible courses) are listed but can't be added to a calendar.
  • Some programs, like Medicine, Pharmacy, Occupational Therapy and Physical Therapy, have different term breaks. Turn off "Skip UM holidays" and delete those days yourself if that's you.
  • Downloading the file again after changing classes won't create duplicates in most calendar apps, because every event has a fixed ID.
  • Your selected classes are saved only in your browser. Nothing is sent to a server.
